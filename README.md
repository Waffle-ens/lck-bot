# LCK Discord Bot

LCK 경기 정보를 Discord에서 슬래시 명령어로 조회하는 봇입니다.

## 주요 기능

### `/로스터`
현재 세트 기준 팀, 포지션, 챔피언 픽, 선수명을 표로 표시합니다.

### `/경기상황`
오늘의 LCK 경기 상태를 판단하여:
- 진행 중: 현재 세트 정보 및 킬/데스 현황
- 시작 전: 예정 시간
- 모두 종료: 경기 결과 요약

### `/경기결과`
최근 완료된 경기의 상세 정보:
- 진행 세트수 및 세트별 진행 시간
- 팀별 챔피언 선택
- 선수별 K/D/A

## 사용 기술

- **Python** 3.11+
- **discord.py** 2.4.0+ — Discord 봇 프레임워크
- **aiohttp** 3.9.5+ — 비동기 HTTP 클라이언트
- **python-dotenv** — 환경 변수 관리

## 데이터 소스

- **일정/결과**: LoL Esports persisted API
- **라이브 통계**: `https://feed.lolesports.com/livestats/v1/window/{gameId}`

### 제한 사항

- 실시간 킬/데스는 프레임별 통계를 바탕으로 추론되며, 정확한 순서를 보장하지 않습니다.
- 밴 픽, 총 딜량, 팀 승패 등은 공개 API의 제한으로 표시되지 않습니다.
- 더 정확한 경기 데이터가 필요한 경우 Riot Esports 공식 API (GRID, PandaScore 등) 검토가 필요합니다.
