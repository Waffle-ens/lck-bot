# LCK Discord Bot

LCK 경기 정보를 Discord 슬래시 명령어로 확인할 수 있는 봇입니다.

## 패치노트

### 최근 추가 기능

- `/어제경기` 명령어를 추가했습니다.
- `/어제경기`에서 매치를 선택하면 완료된 모든 세트를 각각 Embed로 출력합니다.
- `/어제경기` 선수 기록에 K/D/A와 딜 비중을 표시합니다.
- 오늘 경기 API 호출을 줄이기 위해 짧은 메모리 TTL 캐시를 적용했습니다.
- 어제 경기 결과는 KST 00:10 이후 파일 캐시를 시도하고, 데이터가 비어 있거나 누락되면 15분마다 재시도합니다.
- Docker 배포 시 `./data:/app/data` 볼륨으로 어제 경기 캐시를 유지합니다.

## 명령어

### `/명령어`

봇에서 사용할 수 있는 명령어와 기능 안내를 보여줍니다.

### `/경기상황`

오늘 LCK 경기 상태에 맞춰 현재 상황을 보여줍니다.

- 경기 시작 전: 오늘 예정 경기와 시작 시간
- 경기 진행 중: 세트 정보, 팀 킬 수, 골드, 바론, 드래곤, 챔피언 픽, 킬 타임라인
- 다음 세트 준비 중: 곧 경기 시작 안내
- 오늘 경기 종료 후: 경기 요약 안내

### `/로스터`

현재 세트의 출전 로스터와 챔피언 픽을 팀별로 보여줍니다.

### `/경기결과`

오늘 경기 중 보고 싶은 매치를 선택하면, 해당 매치의 세트별 결과를 보여줍니다.

- 팀 킬 수
- 팀 골드와 골드차
- 바론 수
- 드래곤 수와 속성
- 챔피언 픽
- 세트 진행 상태

### `/경기요약`

오늘 완료된 경기의 매치 단위 요약을 보여줍니다.

- 매치 승패
- 세트 스코어
- 세트별 진행시간

### `/어제경기`

어제 경기 중 보고 싶은 매치를 선택하면, 해당 매치의 완료된 세트별 결과를 보여줍니다.

- 팀 킬 수
- 팀 골드와 골드차
- 바론 수
- 드래곤 수와 속성
- 챔피언 픽
- 선수별 K/D/A
- 선수별 딜 비중

## 쿨다운

API 안정성을 위해 명령어 호출 간격을 제한합니다.

- `/경기상황`: 유저당 30초, 서버당 10초
- `/명령어`: 유저당 30초, 서버당 10초
- `/로스터`: 유저당 2분, 서버당 30초
- `/경기결과`: 유저당 3분, 서버당 30초
- `/경기요약`: 유저당 3분, 서버당 30초
- `/어제경기`: 유저당 3분, 서버당 30초

쿨다운 안내는 요청자에게만 보이는 Discord 메시지로 표시됩니다.

## 캐시 정책

API 안정성과 응답 속도를 위해 캐시를 사용합니다.

- 오늘 경기 일정과 상세 정보: 짧은 메모리 캐시
- 실시간 경기 window 데이터: 15초 메모리 캐시
- 실시간 details 데이터: 60초 메모리 캐시
- 어제 경기 결과: `data/cache` 파일 캐시

어제 경기 캐시는 KST 00:10 이후 생성합니다. 선수별 K/D/A, 딜 비중, 팀 킬/골드, 픽 정보가 비어 있거나 누락되면 완료 캐시로 확정하지 않고 15분마다 다시 시도합니다.

## 데이터 안내

이 봇은 공개 LoL Esports 데이터를 기반으로 동작합니다. 공개 데이터에서 안정적으로 제공되지 않는 항목은 표시하지 않습니다.

현재 표시하지 않는 항목:

- 밴 챔피언
- 총 딜량(선수별 딜 비중은 `/어제경기`에서 표시)
- 유충
- 전령
- 확정 이벤트 단위 킬 로그

킬 타임라인은 실시간 이벤트 로그가 아니라 프레임별 K/D 변화 기반으로 추론합니다. 동시에 여러 킬이 발생하면 한 줄에 묶여 표시될 수 있습니다.
